Linux Korean Input Method Installer

Select your Linux distribution and edition to generate a tailored fcitx5-hangul or kime setup script.

⚡ 0단계: 배포판 선택 없이 한 줄 자동 설치 (권장)

git 설치도, 실행 권한(chmod +x) 변경도 필요 없습니다. 터미널에 아래 명령어 한 줄만 붙여넣으면 사용 중인 배포판(Garuda, Arch, Mint, Ubuntu, Fedora 등)을 자동 감지해 설치합니다. 대부분 0단계 스크립트로 한방에 설치가 끝나며, 설치가 완료되면 1단계로 가실 필요가 없습니다. 

curl -fsSL https://raw.githubusercontent.com/stream9k/korean_input/main/install.sh | sudo bash

💡 파일로 직접 받으신 경우 권한 변경(chmod +x) 없이 sudo bash ~/Downloads/install.sh 로 바로 실행할 수 있습니다.

📋 1단계: 배포판 선택

원하시는 데스크톱을 클릭하세요

📄 2단계: 설치 방법 선택 (방법 A 또는 방법 B 중 하나만 실행하세요)

아래 방법 A(원라인 명령어로 터미널에서 즉시 실행)와 방법 B(파일로 다운로드하거나 복사해서 실행) 중 편한 방식 하나만 선택하여 실행하세요. (둘 다 하실 필요가 없습니다!)

⚡ 방법 A: 터미널 한 줄 실행 (가장 추천 — 다운로드 불필요)

터미널(Ctrl+Alt+T)을 열고 아래 명령어를 복사해 붙여넣으면 즉시 설치됩니다. 

curl -sL ... | sudo bash
또는 (OR)

💾 방법 B: 스크립트 파일 직접 다운로드 / 코드 검토

스크립트 코드를 직접 검토하거나, 다운로드 폴더에서 파일로 직접 실행할 때 사용합니다.

✅ 3단계: 설치 후 검증

# 재로그인 후 실행
fcitx5-diagnose

# 환경변수 확인
env | grep -i im_module

# 프로세스 확인
pgrep -af fcitx5

# 설정 확인
cat ~/.config/fcitx5/profile
cat ~/.config/fcitx5/config

# 강제 재시작
fcitx5 -r
